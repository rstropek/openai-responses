# Basics of the OpenAI Responses API

This sample demonstrates how to build a simple interactive chatbot using the OpenAI Responses API. It shows a basic conversation loop where the user can chat with the AI assistant in the terminal.

You will learn how to:

* Set up the OpenAI client with an API key
* Use a developer system prompt loaded from a file to guide the assistant's behavior
* Maintain a multi-turn conversation by passing the full message history to each API call
* Build an interactive command-line chat loop with user input and assistant responses
